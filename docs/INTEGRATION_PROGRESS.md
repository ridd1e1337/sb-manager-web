## 边界

客户代理账本由 Marzban 管理，商城通过 API 发放权益。sb-manager-web 管理独立的 sing-box 节点；两者不同时修改同一个代理进程。客户账号不能调用特权运维任务。已有改动保留；生产服务不用于安装/破坏性测试。

只有完成上表对应范围的实际检查才更新状态，不以接口清单或单元测试代替完整业务验收。

## 客户套餐规则实施方案

用户已确认以独立 Go 商城替换 Django。SNTP 保持 Vue/JavaScript，Marzban 保留原生 Python 服务。Go 项目位置为 `airport-stack/commerce`，接口、支付、开通与周期 worker 已整体迁移，默认 Compose 使用 Go。Django 保留 55 项回归测试和旧账本导出入口；Go 通过所有权标记防止旧进程继续写账。

- 保留旧订单的“累计额度+有效期”语义，不把已有客户无提示迁移为月度重置。
- 新周期套餐默认每 30 天恢复套餐额度，未用完不结转。同套餐在有效期内续费只延长有效期，不提前重置流量；过期后重开一个周期。支持多周期预付。
- 不限时流量包不设置到期时间、不定时重置；再次购买叠加剩余额度。
- 周期调度保存在商城，代理累计用量由 Marzban 管理。每次周期切换先持久化绝对额度目标，再调用 API；不依赖可重复清零的远程请求。
- 新业务的套餐类型、周期、节点组与额度都必须进入订单快照，前端展示同一份规则。
